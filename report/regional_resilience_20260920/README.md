# Региональная устойчивость

Основной интерактивный отчёт: Региональная_устойчивость.html (полностью автономный). PDF включён в архив.

25 рисунков в PNG и SVG, агрегированные CSV, реестр источников. Индивидуальных строк клиентов в комплекте нет.

Повторение анализа: Python 3.9, зависимости проекта tmp/research_pydeps, скрипт analysis/regional_resilience.py. Создание PDF/HTML: bundled Python 3.12, analysis/build_regional_resilience_report.py. Исходные clean-файлы и предыдущие таблицы должны находиться в тех же папках. Базовые оценки и SHA-256 проверяются автоматически.

Bootstrap и permutation seeds = 260920. Все отрицательные объёмы сохранены как чистые литры; альтернативный индекс построен по положительным объёмам.
